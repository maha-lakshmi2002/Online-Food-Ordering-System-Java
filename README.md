# Online Food Ordering System - Java

## Project Description
Online Food Ordering System is a Java-based application used to manage food ordering activities.

This system allows customers to view restaurants and food items, place orders, and manage their orders easily.

## Technologies Used
- Java
- Maven
- MySQL
- JDBC
- Eclipse IDE

## Main Modules
- Customer Management
- Restaurant Management
- Food Management
- Order Management

## Features
- Add and manage customers
- Add and manage restaurants
- Add and manage food items
- Place food orders
- View order details
- Store and retrieve data from database

## Project Structure
- controller
- model
- repository
- util
- main

## Database
MySQL database is used to store customer, restaurant, food and order details.

## How to Run
1. Open the project in Eclipse.
2. Configure Java and Maven.
3. Configure MySQL database.
4. Update database connection details.
5. Run the Main class.
